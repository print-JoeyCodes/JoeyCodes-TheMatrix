JoeyCodes TheMatrix Project for the HalfLife warmup

5 WS281B-8 Led chips soldered together and hot glued to cardboard. Powered by a 9V battery and an Arduino Nano, I can display any combonations of colors using the FastLED library.

Using nested arrays, I was able to encode animation frames to create scrolling text and images.
